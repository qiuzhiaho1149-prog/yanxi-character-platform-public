# dsh-yanxi-life

嫣汐的生活沙箱：给她自己的手和脚，但只在生活目录里。

工具：

- `life_list`：列生活目录
- `life_read`：读文本文件（最大 256KB，二进制拒绝）
- `life_write`：写文本文件（最大 512KB，原子写）
- `life_mkdir`：建文件夹

根目录默认 `~/.dsh-yanxi/life`，可用 `DSH_LIFE_ROOT` 覆盖。
不提供 shell、系统目录、绝对路径、任意网络。

## 安全

- 只接受相对路径
- 解析后必须仍在生活目录内
- 拒绝越界、`..`、绝对路径、NUL
- 读写有大小上限
- 不暴露给 QQ 会话以外的任何东西
