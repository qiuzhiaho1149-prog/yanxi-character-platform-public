# 06 · 运维与故障恢复

## 1. 服务清单

| 服务 | 作用 | 管理 |
| --- | --- | --- |
| dsh-yanxi | DSH + 嫣汐引擎 + QQ 插件 | systemd |
| napcat | QQ 协议端 | Docker |
| napcat-budget-proxy | 每日 500 条出站预算 | systemd |
| napcat-owner-gate | owner 好友/群邀请自动同意 | systemd |

## 2. 常用命令

```bash
# 状态
sudo systemctl status dsh-yanxi napcat-budget-proxy napcat-owner-gate
sudo docker ps --filter name=napcat

# 日志
tail -100 /home/<user>/dsh-yanxi.log
sudo docker logs --tail 100 napcat
tail -50 /home/<user>/napcat/budget-proxy.log
tail -50 /home/<user>/napcat/owner-gate.log

# 重启
sudo systemctl restart dsh-yanxi
sudo docker restart napcat

# 配置检查
dsh --profile yanxi --dump-config | less
```

## 3. QQ 掉线恢复

1. 看 NapCat 日志：
   ```bash
   sudo docker logs --tail 80 napcat
   ```
2. 日志出现二维码 / Login Error：
   - 重新生成二维码
   - 用**小号**扫码
   - 不要把主号登进 NapCat
3. 扫码后确认：
   ```bash
   sudo docker logs --tail 50 napcat
   ```
   出现 `接收 <-` / `发送 ->` 即在线
4. 不要频繁重启 NapCat，机房 IP 风控会加重。

## 4. 预算代理

- 状态文件：`/home/<user>/napcat/budget.json`
- 默认每日 500 条
- 只统计 `send_*` 动作
- 超额返回假成功回执，不真实发送
- 修改上限：改 systemd 环境变量 `QQ_DAILY_LIMIT` 或脚本常量

## 5. 语音

- 克隆：`/home/<user>/minimax_voice.py`
- venv：`/home/<user>/voice-venv`
- 参考音频：`/home/<user>/voice-ref2.wav`
- 克隆音色：`MINIMAX_VOICE_ID=yanxiClone02`
- MiniMax 余额不足 → 错误 `1008 insufficient balance`
- TTS 失败会退回 Edge（如果配置了 fallback），但克隆音色需要 MiniMax

### 语音验证

```bash
# 1. 生成
sudo bash -c 'set -a; . /etc/dsh-yanxi.env; set +a; /home/<user>/voice-venv/bin/python /home/<user>/minimax_voice.py tts "测试一句" /tmp/test.mp3 happy 1.02 1'
# 2. 检查时长
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1 /tmp/test.mp3
```

## 6. 图片

## 7. 备份

至少每日备份：

- `/var/lib/yanxi/characters/yanxi/`（事件流、日记、配置、owner cookie）
- `/home/<user>/.dsh/profiles/yanxi/`（profile/配置）
- `/home/<user>/napcat/config/`（NapCat 配置）
- `/etc/dsh-yanxi.env`（密钥，加密保存，不进普通备份）

恢复顺序：

1. 恢复 profile
2. 恢复 `/var/lib/yanxi/characters/yanxi`
3. 恢复 NapCat 配置
4. 启动服务
5. 检查事件流/日记/账号

## 8. 密钥

- `/etc/dsh-yanxi.env` 权限 600
- 不要在聊天、文档、仓库中复制
- MiniMax/DeepSeek key 建议定期轮换
- 轮换后改 env，重启 dsh-yanxi

## 9. 常见故障

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 群里每句都回复 | `requireMention: false` | 改成 true + `groupWakeProbability` |
| 语音工具“这件事我做不到” | guard 白名单没有工具 | 加 HER_TOOLS/允许名单并重启 |
| 图片看不到 | 视觉描述未注入/模型无视觉 | 看 `vision-inline`、`DEEPSEEK_API_KEY` |
| 语音发不出 | MiniMax 余额/工具 guard | 查 1008、HER_TOOLS |
| 语音“死人感” | 导演 max_tokens 太小/回退原话 | 检查导演 JSON、max_tokens |
| 账号掉线 | 机房 IP 风控 | 重新扫码，不频繁重启 |
| 云端改完没生效 | 服务未重启/配置被 settings 覆盖 | dump-config + restart |
