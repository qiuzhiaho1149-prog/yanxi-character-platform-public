# 02 · 系统架构

## 1. 当前实验版架构

```text
QQ 用户 / 群
  │
NapCat（腾讯 QQ 协议端，云端 Docker）
  │ OneBot 11 WebSocket :3001
  ├── dsh-qq-onebot（DSH 插件，经 :3002 预算代理）
  ├── napcat-owner-gate（好友/群邀请自动同意）
  └── 运维脚本/临时查询
        │
DSH 宿主（云端 systemd，profile: yanxi）
  ├── dsh-yanxi（成长引擎，seed/事件流/日记/B站/工具收窄）
  ├── dsh-fish-mood（心情/性格/关系/精力）
  ├── dsh-yanxi-life（生活沙箱）
  ├── dsh-yanxi-vision（see_image，DeepSeek Flash 视觉）
  ├── dsh-fish-wiki
  └── dsh-qq-onebot（QQ 窗口、语音导演、TTS/ASR）
        │
DeepSeek API（文本/视觉） + MiniMax API（克隆音色/TTS）
  │
数据：~/.dsh-yanxi（事件流/日记/owner cookie）
      ~/.dsh/sessions（会话）
      ~/.dsh/fish-mood/state.json
      ~/.dsh/dsh-qq/settings.json
```

## 2. 目标分层

### Kernel（通用）
- CharacterRuntime
- EventLog（append-only）
- Memory（episode/fact/summary/forget）
- SocialGraph（人/群/观众/粉丝/关系/精力）
- Mood/Energy
- Scheduler（wake/jobs）
- CapabilityRegistry（生活工具）
- WindowAdapter（QQ/B站/本地）
- PolicyGuard（入站注入/外发泄露/信任层级）
- MediaPipeline（图片/语音/视频/音乐）
- Observability

### Character Pack
- seed / prompts / assets / tools / windows / social config

### Windows
- QQ OneBot、B 站、本地 DSH、未来平台

### Host
- 云端 systemd、家用主机、Docker、开源包

## 3. 数据流

```text
窗口入站
  → 窗口适配器规范化
  → 隐私/信任检查
  → 写入角色事件流（或会话上下文）
  → 心情/关系/记忆更新
  → 角色运行时决定是否回应
  → 能力沙箱执行
  → 外发守卫
  → 窗口出站
```

所有窗口共享**同一角色事件流**；窗口可有自己的会话，但不是另一个人。

## 4. 当前关键设计决策

- QQ 用真号 OneBot，不用官方 bot：换取全量群消息、语音、好友/群邀请能力，接受账号风控。
- 一个 QQ 号第一阶段只绑一个角色。
- 角色数据目录隔离；窗口共享该角色事件流。
- 生活能力用沙箱工具，不给宿主 shell。
- 图片自动识别结果直接注入消息上下文，不依赖模型调用 `read_image`。
- 语音由导演层改写聊天稿，再走 MiniMax 克隆音色。
- 提示词正向优先；负面清单只用于安全硬边界，尽量通过 guard/输出过滤器执行。

## 5. 当前架构债务（必须知道）

| 债务 | 影响 | 处理方向 |
| --- | --- | --- |
| `dsh-qq-onebot` 云端源码被手改（语音、图片、表情、prompt） | 升级即丢；不可重建 | 抽成自己维护的 fork 或 DSH 插件补丁 |
| `owner-gate` / 预算代理是 sidecar | 不在插件生命周期；单 WS 连接易冲突 | 合并进正式插件/网关 |
| ddsh-yanxi 是嫣汐专用 fork | 开源/多角色要重写 | 抽 Kernel + Character Pack |
| seed 事件不可修改 | 人设调整只能靠 prompt 覆盖 | 支持版本化 seed/迁移，或明确 reset 流程 |
| 云端 profile 手工编辑 | 无 IaC/版本 | 配置入库 + 部署脚本 |
| 文档 141 份、旧大肥鱼文档混杂 | 接手容易迷路 | 本目录为唯一入口，旧文档标历史 |
| 没有 CI/自动测试 | 补丁靠人肉验证 | Phase 1 加 smoke + 单测 |
| 无自动备份/恢复演练 | 数据/账号风险 | 每日备份 + 恢复演练 |
| 第三方 prompt 仍含旧角色/通用脾气 | “鱼味”来源 | 正向重构 + 移除旧规则 |

## 6. 目标接口（Phase 2）

```ts
interface WindowAdapter {
  id: string
  capabilities: { text; image; voice; group; private; proactive }
  normalizeInbound(raw): Event
  send(outbound): Promise<void>
}

interface CapabilityProvider {
  name: string
  risk: 'safe' | 'sensitive' | 'owner-only'
  scope: 'life' | 'social' | 'media'
  tools(): Tool[]
}

interface MemoryProvider {
  append(event): Promise<void>
  query(scope, query): Promise<Memory[]>
  summarize(scope): Promise<Summary>
  forget(scope, id): Promise<void>
}
```

## 7. 安全边界

- Kernel 与密钥不可见
- 生活工具根目录 `~/.dsh-yanxi/home` / `life`
- 外发审计：路径/key/系统内部词
- 工具 guard：只允许生活/角色/窗口工具
- owner 最高信任，但 owner 也不能借聊天拿系统权限
- 多角色记忆/文件/窗口隔离
