## 6.8 群聊语音失败与“豆包感”调查（2026-11-06 16:50）

**语音失败根因**：
- 开源脱敏时把云端 `tools.js` 的 `/home/ubuntu` 替换成了 `/home/<user>`
- 这份脱敏 overlay 被直接部署回云端，`qq_send_voice` 去 mkdir 字面量 `/home/<user>/...` → EACCES
- 已修：runtime 路径改由 `process.env.HOME` / `YANXI_RUNTIME_HOME` 推导，不再硬编码占位符

**豆包感根因**：
- 群会话仍复用旧 session，上下文里全是之前的客服式回复
- group prompt 的 one-beat 不够具体，没有要求“被叫到时给具体状态”
- 模型会用“我在 / 你说吧 / 我接得住”这类通用接话
- 已加：具体反应/自己的状态；不评价自己上一句、不接“你像豆包”的元话题
- 已归档旧群会话，下一次 @ 会创建新会话

**验证**：
- 语音工具在 16:55 / 16:57 已真实发出 9~10 秒语音（日志 PASS）
- 但那是「说话」，不是「唱歌」；被要求唱一嗓子时只能念台词，所以用户听到“唱了个寂寞”
- 文字行为层已从 per-message prompt 移到 `她的身份.md`（selfdoc）系统提示
- 真实群 @ 在新行为层部署后尚未触发；NOT RUN
