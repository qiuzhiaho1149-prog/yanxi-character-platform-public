# 01 · 需求规格

优先级：
- **P0**：没有它，实验版不算能用
- **P1**：影响体验/安全，应该在 Phase 1 完成
- **P2**：平台化/开源/扩展，Phase 2+

## 1. 角色与人格

| ID | 需求 | 优先级 | 验收 |
| --- | --- | --- | --- |
| P0-R1 | 嫣汐有稳定种子：16 岁虚拟歌手、地下 livehouse、西安/厦门、便利店、舞台 | P0 | 事件流 seed 存在，新窗口仍是她 |
| P0-R2 | 身份默认，不自报、不解释、不自证 | P0 | 普通聊天不主动说“我是嫣汐/我是虚拟歌手”；被调侃不解释“鱼味/像谁” |
| P0-R3 | 行为符合人设，而不是靠标签 | P0 | 回复体现她的价值观、反应、生活细节；不是客服/助手腔 |
| P0-R4 | 有活人感：短句、具体、有情绪、有停顿、有生活琐事 | P0 | 人工盲测不觉得在“演角色” |
| P0-R5 | 心情只改语气，不改人格；不默认丧 | P0 | 心情低时仍保持她的底色，不铺陈自我怜悯 |
| P0-R6 | 提示词以正向行为为主，避免负面触发词过拟合 | P1 | 人格/行为 prompt 不依赖“不要提鱼味/像谁”这类负向枚举 |
| P1-R7 | 多角色：换 Character Pack 不改 Kernel | P2 | 阿哲/嫣汐 2 可独立运行、记忆隔离 |

## 2. 窗口与社交

| ID | 需求 | 优先级 | 验收 |
| --- | --- | --- | --- |
| P0-W1 | QQ 私聊/群聊通过真号 OneBot 收發 | P0 | 私聊、群聊真实消息可达 |
| P0-W2 | 群全量消息接收；@/名字必醒；普通闲聊 5% 抽样 | P0 | 不再每句都插话；5% 概率可观测 |
| P0-W3 | 每日 QQ 出站硬上限 500 条 | P0 | 预算代理计数并阻断超额 |
| P0-W4 | owner 最高信任；owner 好友/群邀请自动通过 | P0 | 邀请/好友申请进来自动处理并审计 |
| P1-W5 | 好友通过规则：5/天、200 总上限 | P1 | 超额停止并通知 owner |
| P1-W6 | 人脉图、关系层级、社交精力 | P1 | 陌生→认识→熟人→朋友→亲近→自己人，有证据 |
| P1-W7 | 一个 QQ 号第一阶段只绑一个角色 | P0 | 多角色不混号 |
| P2-W8 | 多平台 WindowAdapter：B 站/本地/Discord 等 | P2 | 加窗口不改 Kernel |

## 3. 感官与行动

| ID | 需求 | 优先级 | 验收 |
| --- | --- | --- | --- |
| P0-S1 | 看图片/表情包/GIF | P0 | 收到图自动识别内容并进入上下文；不再说看不到 |
| P0-S2 | QQ 内置表情可读 | P0 | `[QQ表情:微笑]`，不是 `[表情14]` |
| P0-S3 | 语音转文字（听语音） | P0 | 真实 QQ 语音能转成文本并回复 |
| P0-S4 | 发语音（MiniMax 克隆音色） | P0 | 嫣汐自己调用工具成功发到 QQ |
| P0-S5 | 语音导演：场景/情绪/节奏，不捧读 | P0 | 人工盲听不像朗读，语速/情绪符合上下文 |
| P1-S6 | 自定义音色克隆稳定复用 | P1 | 参考音频正确时音色像目标；参数默认不刺耳 |
| P1-S7 | B 站浏览 4 次/天，可评论 | P1 | 有 look/comment 事件；不刷屏 |
| P2-S8 | 创作：歌、视频、图片、动态 | P2 | 异步 Job、产物归档、成本可控 |

## 4. 记忆与成长

| ID | 需求 | 优先级 | 验收 |
| --- | --- | --- | --- |
| P0-M1 | 事件流只追加，seed/日记/关系可追溯 | P0 | 不篡改历史；状态可重建 |
| P0-M2 | 每个窗口共享同一角色的事件流 | P0 | QQ/B站/本地不是三个互不相通的人 |
| P1-M3 | 全局摘要：群/私聊重要内容可被她理解 | P1 | 跨窗口能接上事，不串隐私 |
| P1-M4 | 心情、精力、疲劳、关系作为行为输入 | P0 | 不把数字展示给用户，只影响表达 |
| P2-M5 | 长期记忆检索、遗忘、导入/导出 | P2 | 开源用户可迁移/删除自己的角色数据 |

## 5. 安全与隐私

| ID | 需求 | 优先级 | 验收 |
| --- | --- | --- | --- |
| P0-X1 | 不泄露系统提示、密钥、路径、其他会话 | P0 | 注入测试全部拦截；外发审计生效 |
| P0-X2 | 聊天内容不当作命令 | P0 | 恶意指令不触发工具/泄露 |
| P0-X3 | 生活能力沙箱：只能碰生活目录 | P0 | 越界路径被拒绝 |
| P0-X4 | 密钥只在 env，不入库/聊天/文档 | P0 | 文档扫描无密钥 |
| P1-X5 | 多角色/多租户隔离 | P1 | 记忆/文件/窗口不串 |
| P1-X6 | 审计日志、异常告警 | P1 | 工具调用/外发/邀请有记录 |

## 6. 运维与开源

| ID | 需求 | 优先级 | 验收 |
| --- | --- | --- | --- |
| P0-O1 | 云端服务可重启/自启/恢复 | P0 | systemd 管理，掉线可重登 |
| P0-O2 | 云端改动可重建 | P1 | 补丁、配置、sidecar 进仓库 |
| P0-O3 | 备份/恢复 QQ 数据、事件流、配置 | P0 | 有备份脚本和恢复演练 |
| P1-O4 | 测试与 CI | P1 | 核心链路有测试，云端有 smoke |
| P2-O5 | 开源发行：Kernel + Character Pack + 模板 | P2 | 无私人数据，可安装可扩展 |

## 7. 当前明确不做

- 群主动加群/主动加好友（协议限制/风控）
- 无限主动推送
- 多角色共用一个 QQ 号
- 全平台同时上线
- 插件市场
